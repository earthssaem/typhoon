# 수학여행 D-1: 태풍이 올라온대!! 🌀

기상청 자료를 분석해 수학여행지의 날씨를 판단하고, 실제 날씨에 맞는 옷과 준비물을 챙기는
**고등학생 대상 체험형 웹앱** — 해커톤 출품용 **프로토타입**입니다.

> “내일 수학여행인데 태풍이 올라온대!!” 라는 상황에서 태풍 구조와 위치별 날씨를 시뮬레이터로
> 체험하고, 목적지별 일기도·위성·레이더영상과 태풍 예상경로를 분석해 여행지의 날씨를 판단하고
> 필요한 준비물을 선택합니다.

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## 활동 흐름 (STEP 1~8)

| STEP | 화면 | 내용 |
|------|------|------|
| 1 | 문제 상황 | “태풍이 올라온대!!” 상황·목표 제시 |
| 2 | **태풍 구조 시뮬레이터** | 관측 지점을 드래그해 눈·눈벽·비구름대·위험/가항반원의 날씨를 실시간 탐색 |
| 3 | 목적지 선택 | 서울·부산·제주 중 선택 (사례 데이터·배경만 교체) |
| 4 | 자료 분석 | 일기도 → 위성영상 → 레이더영상 차례로 확인 |
| 5 | 예상경로 분석 | 예상경로 중심선·70% 확률반경·강풍/폭풍반경으로 영향·반원 판단 |
| 6 | 최종 예보 카드 | 기온·강수·바람·야외일정 판단 + 판단 근거 카드 선택 |
| 7 | 캐리어 꾸리기 | 10칸 제한 캐리어에 드래그앤드롭(또는 클릭)으로 준비물 담기 |
| 8 | 실제 엔딩 | 실제 경로·날씨 공개 → 캐리어 물품만으로 캐릭터 옷 입히기 → 규칙 기반 채점 + 종합 피드백 |

## 구현 메모 (프로토타입 범위)

- **공통 게임 엔진 + 목적지별 사례 데이터팩** 구조 (명세 10).
  - 게임 진행 상태 머신: `src/App.tsx`
  - 사례 데이터: `src/data/cases.ts` · 캐리어 물품: `src/data/items.ts`
  - 시뮬레이터 물리 모델: `src/game/typhoon.ts`
  - 규칙 기반 채점·옷차림·피드백: `src/game/scoring.ts`
- 진행 상태는 `localStorage`에 저장됩니다(`처음부터` 버튼으로 초기화).
- **AI 없이도 채점·엔딩이 동작**하도록 종합 피드백을 규칙 기반으로 생성합니다
  (생성형 AI API 연결 시 더 풍부한 코멘트로 확장 가능).

### 기획서 대비 단순화한 부분

테스트/기획 단계 프로토타입이라 의존성을 최소화했습니다. 본 구현에서는 외부 시각화 라이브러리
대신 자체 구현을 사용합니다(쉽게 교체 가능한 자리):

- 지도/예상경로: Leaflet → **SVG 모식 지도** (`src/components/svg/`)
- 그래프: Chart.js → 카드형 수치 표시
- 드래그앤드롭: dnd-kit → **포인터 이벤트 / 클릭 토글**
- 일기도·위성·레이더: 실제 WebP 영상 대신 **교육용 합성 SVG 이미지**

> ⚠️ **모든 사례(일기도·위성·레이더·예상경로·실제 관측값)는 교육용 「예시 데이터」입니다.**
> 실제 기상청 자료로 교체하는 것을 전제로, 데이터 구조와 교육적 대비(위험/가항반원, 강풍반경
> 포함 여부 등)를 분명히 보여주도록 구성했습니다.
